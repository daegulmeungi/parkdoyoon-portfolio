# 서울시 의료 공백 분석: 행정동 × 진료과 취약 지수

| 항목 | 내용 |
|---|---|
| **기간** | 2026.06 |
| **형태** | 팀 프로젝트 · 3인 (소셜 인텔리전스 수업) |
| **담당** | 강북구 · 내과 분석, 발표(문제 정의 파트) |
| **방법** | 취약 지수 설계 · 클러스터링 |

---

## 1. 배경 · 목표
의료 접근성은 보통 자치구 단위로 이야기합니다. 하지만 같은 구 안에서도 *동네마다, 진료과마다* 부족한 정도가 다릅니다.
이 프로젝트는 서울시 안에서 **어느 지역의 어떤 진료과가 부족한지를 행정동 단위로 진단**하는 것을 목표로 했습니다.

## 2. 분석 과정
```
 자치구 단위 분석 ─▶ 취약 구 3곳 선정 (금천구 · 관악구 · 강북구)
        ▼
 진료과 5개 × 행정동별 취약 지수 계산 (공급 대비 수요)
        ▼
 클러스터링 ─▶ 행정동별 의료 공백 패턴 분류
```

## 3. 결과
| 유형 | 행정동 수 |
|---|:-:|
| 소아청소년과 부족형 | 24 |
| 심장혈관 부족형 | 8 |
| 산부인과 부족형 | 7 |
| 상대적 공급 충분형 | 5 |

- 심장혈관흉부외과는 병원이 아예 없는 동이 대부분이어서, 상대적 부족이 아닌 **절대적 공급 부족**이었습니다.
- 5개 진료과가 모두 부족한 동도 5곳이었습니다.
- **시사점**: 취약 구에 병원을 일괄적으로 늘리기보다 **행정동 × 진료과별 맞춤 전략**이 필요합니다.

## 4. 한계 · 개선 방향
- 공급 지표로 병원 수와 진료과 수만 썼습니다. 야간 · 응급 진료 여부나 전문의 수처럼 *실제로 진료받을 수 있는지*를 보여주는 지표를 반영하는 것이 다음 과제입니다.
