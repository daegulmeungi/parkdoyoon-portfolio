# 자리픽 ZARIPICK · AI 데이터 기반 최적 입지 컨설팅 비서

창업 목적과 조건을 입력하면 **유동인구 · 상권 · 교통 · 생활 인프라 · 부동산 시세**를 종합 분석해
서울 내 최적 입지를 추천하고, **자금 계획과 금융 수요를 고려한 맞춤 금융서비스**까지 제안하는 웹 서비스 프로토타입.

## 실행 방법

**① 실데이터로 실행 (권장)** : seoul_db 기반 서울 1,030개 상권

```bash
cd server && copy .env.example .env && npm run build:cache && npm start
```

http://localhost:8787 접속. 설치할 패키지는 없습니다(Node 22.5+ 내장 모듈만 사용).

**② 서버 없이 실행** : `index.html` 을 그대로 열면 목업 15개 상권으로 동작합니다.

상단바 배지에 현재 어느 쪽인지 표시됩니다: `실데이터 seoul_db · 상권 1,030개` 또는 `목업 데이터 · 서버 미연결`.

## AI 해설 켜기

`server/.env` 의 `ANTHROPIC_API_KEY` 에 키를 넣고 서버를 재시작하면 됩니다.
**키가 없으면 규칙 기반 해설로 자동 동작**하므로 서비스는 그대로 쓸 수 있습니다.
자세한 내용은 [server/README.md](server/README.md) 참고.

- 정적 자산은 `?v=YYYYMMDD` 캐시 버스팅 쿼리로 참조합니다. 배포 시 자산 변경마다 버전을 올리세요.
- 폰트는 SUIT Variable을 jsDelivr CDN에서 로드합니다(`style.css` 상단 `@import`).

### 점수 색상 스케일

모든 지표가 **하나의 색 기준**을 공유합니다. 색만 보고 좋고 나쁨을 판단할 수 있게 하기 위함입니다.

| 클래스 | 점수 | 색 | 라벨 |
|---|---|---|---|
| `s1` | 0–39 | 빨강 `#e5484d` | 매우 낮음 |
| `s2` | 40–54 | 주황 `#f07316` | 낮음 |
| `s3` | 55–69 | 황색 `#d9a107` | 보통 |
| `s4` | 70–84 | 연두 `#62ab2e` | 높음 |
| `s5` | 85–100 | 초록 `#0e9f6e` | 매우 높음 |

`s1`~`s5` 클래스가 `--sc`(진한 색)와 `--sc-weak`(배경용 연한 색) 변수를 내려주고,
`.sc-text` / `.sc-fill` / `.lvl` / `.graded` 등이 이를 참조합니다.
색을 바꾸려면 `:root`의 `--sc1`~`--sc5`만 수정하면 전 화면에 반영됩니다.

**낮을수록 좋은 지표**(임대료·경쟁밀도·폐업률·리스크 수준)는 `app.js`의
`invert(값, 최악, 최선)`으로 0–100 '좋음 점수'로 변환한 뒤 같은 스케일을 적용합니다.
등급 판정은 `grade(점수)` 하나만 사용하므로 기준이 흩어지지 않습니다.

### 아이콘

시스템 이모지는 OS·브라우저마다 모양이 달라 사용하지 않고, 24×24 stroke 기반 SVG 심볼 39종을
`icons.js`가 `<body>` 최상단에 스프라이트로 주입합니다.

```html
<svg class="icon"><use href="#i-pin"/></svg>   <!-- 정적 마크업 -->
```
```js
icon('coin', 'icon icon-lg')                    // JS 생성 마크업
```

`currentColor`를 상속하므로 부모의 `color`만 바꾸면 색이 따라오고,
크기는 `.icon-sm / .icon-lg / .icon-xl`로 조절합니다. 업종·창업목적 아이콘은
`data.js`의 `icon` 필드로 지정되어 있어 항목 추가 시 심볼 이름만 넣으면 됩니다.

## 스코어링 로직 (`app.js`)

6개 지표(수요기반·업종적합·교통·인프라·예산적합·안정성)에 **창업 목적별 가중치**를 적용해 100점 환산.

**운영 형태가 수요 지표의 정의를 바꿉니다.**
- 방문 중심 → 수요 = 유동인구 + 증감 추세
- 배달 중심 → 수요 = 배후 주거·직장 인구, 교통 가중치 ×0.5, 예산 가중치 ×1.3
- 혼합 → 두 값의 평균

가중치 변경 후 합이 1이 되도록 재정규화합니다.
초기 개설비용이 예산을 초과하면 총점에 페널티를 적용하고 카드에 `예산 초과` 배지를 표시합니다.

**매출·영업이익·BEP 도달 시점 예측을 제거**했습니다. 대신 다음만 제공합니다.

| 제공 | 근거 |
|---|---|
| 유동인구, 배후 인구, 경쟁 밀도, 폐업률, 매출지수 | 관측된 상권 지표 |
| 임대료, 보증금·권리금, 개설비용, 월 고정비 | 상권 시세 기반 환산 |

## 남은 작업 (연동 포인트)

1. **Firebase Authentication**
   - `index.html` 하단 스크립트의 `[data-go]` 핸들러 → 카카오/Google/이메일 로그인으로 교체
   - `app.html` 헤더 아바타에 실제 사용자 표시, 미로그인 시 `index.html`로 리다이렉트

2. **Firestore (코인 지갑)**
   - `app.js`의 `loadWallet / saveWallet / spendCoins`가 유일한 접점
   - 스키마 예시: `users/{uid}` → `{ balance, month, log[] }`
   - 월 10코인 충전은 **Cloud Functions 스케줄러**로 이관 (현재는 클라이언트에서 월 비교로 처리 → 조작 가능하므로 반드시 서버 이관 필요)
   - 코인 차감도 서버(Functions)에서 트랜잭션 처리 권장

3. **상권 DB 연동**
   - `assets/js/data.js`의 `AREAS`를 API 응답으로 교체 (`fetch('/api/areas')`)
   - 필드 스키마는 현재 목업 객체 형태 유지 시 나머지 코드 수정 불필요
   - 확장 계획: 서울 → 수도권 → 전국 (지역 필터 UI 추가 필요)

4. **금융상품 데이터**
   - `FIN_PRODUCTS`의 금리·한도·자격요건을 실제 기관 데이터로 교체
   - 현재 금리/한도는 데모용 가정값이며 화면에 고지 문구가 포함되어 있음

5. **PDF** (`exportPdf`. 건드릴 때 아래 제약 3가지를 반드시 지킬 것)
   - html2pdf.js(CDN)로 A4 다단 페이지 PDF 파일을 직접 다운로드 (`자리픽_입지분석_상권명_날짜.pdf`)
   - **제약 ①** html2canvas는 DOM에서 분리된 노드를 폭 0으로 측정해 **백지**로 렌더한다 → 클론을 실제로 body에 붙여야 한다
   - **제약 ②** 뷰포트 밖(`left:-10000px` 등)에 두어도 **백지**가 된다 → 화면 좌상단(`position:absolute; left:0; top:0`)에 두고 `z-index:-1`로 가린다.
     같은 이유로 스크롤된 상태에서는 최상단 holder가 화면 밖이므로, 캡처 전 `scrollTo(0,0)` → 완료 후 원위치 복원한다
   - **제약 ③** html2canvas에 `windowWidth`/`scrollX`/`scrollY`를 넘기면 html2pdf 내부 컨테이너의 좌표계와 어긋나 **좌측이 잘린다** → 넘기지 않는다
   - 캡처 전 `document.fonts.ready`를 await (웹폰트 미로드 시 폴백 폰트로 찍힘)
   - 페이지 나눔: 섹션은 분할 허용, `tr`·`.stat`·`.fin`·`.tl`·`.callout`·`.stat-grid`만 `break-inside: avoid` (`.pdf-doc` 클래스)
   - 라이브러리 로드 실패(오프라인 등) 시 `window.print()` + `@media print`로 폴백
   - 서버 렌더링 PDF가 필요하면 Puppeteer 기반 Functions로 교체

6. **코인 차감 확인 모달**
   - 브라우저 `confirm()` 대신 앱 내 모달(`#appModal`, `appConfirm()`)로 처리
   - 보유/차감/잔여 코인 내역 표시, ESC·백드롭 클릭으로 취소, Enter로 확인

7. **랜딩 모션**
   - 히어로 스태거 등장, 배경 사진 슬로우 줌, 콘솔 목업 플로팅·게이지 채움, 스크롤 리빌, 지표 카운트업
   - 기본으로 동작하고 `@media (prefers-reduced-motion: reduce)` 에서만 정지하도록 구성 (OS 애니메이션이 꺼져 있어도 보이게)

## 로컬 실행

정적 파일이므로 파일을 그대로 열어도 되지만, 캐시 문제를 피하려면 로컬 서버 권장:

```bash
npx serve .
```

## Firebase Hosting 배포

```bash
firebase init hosting
```

`public` 디렉터리를 현재 폴더(`.`)로 지정한 뒤:

```bash
firebase deploy --only hosting
```
