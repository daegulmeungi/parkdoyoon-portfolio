# 데이터

| 파일 | 포함 여부 | 설명 |
|---|:-:|---|
| `school_health_preprocessed.csv` | 포함 | 전처리 완료본. BMI 컬럼 생성, IQR 이상치 제거, 결측치 처리를 마쳤습니다. EDA · 가설검정 · 회귀분석 노트북은 모두 이 파일만 읽습니다 |
| `(최종) 2023 학생건강검사 데이터 공개자료.xlsx` | 제외 (34MB) | 원자료 |
| `school_health.csv` | 제외 (36MB) | 원자료를 CSV로 변환한 중간 파일 |
| `school_health_2022.csv` | 제외 | 2022년 정제 데이터. 프로젝트 전 개인 사전 탐색 노트북(`src/PreEDA/`)에서만 썼습니다. 실행 결과는 노트북에 남아 있습니다 |

1. 교육부 학생건강정보센터에서 **2023년 학생건강검사 원자료**를 내려받습니다.
2. 위 파일명 그대로 이 폴더에 넣습니다.
