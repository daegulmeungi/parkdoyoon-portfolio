## 30초 요약

| 구분 | 내용 |
|---|---|
| **문제** | 아침식사를 자주 하는 학생은 BMI가 낮을까? |
| **해결** | 정규성·등분산 검정 결과를 보고 <b>비모수 검정(Kruskal-Wallis + Dunn)</b>을 선택하고, 성별 × 학교급 **6개 그룹**별로 회귀분석 |
| **결과** | 6개 그룹 모두 아침식사 빈도에 따라 BMI가 유의하게 다름(Kruskal-Wallis, p < 0.001). 회귀계수 −0.08 ~ −0.39(p < 0.01). 하지만 <b>R² 0.1 ~ 1.2%</b>라서 *"유의하지만 영향은 작다"*고 결론 |
| **내 역할** | 아침식사 ↔ BMI 분석 전체, 데이터 전처리(공동), 발표 자료 제작 |
| **코드로 확인** | [`EDA`](src/EDA/EDA_Breakfast_BMI.ipynb) · [`가설검정`](src/HypothesisTesting/HypothesisTesting_Breakfast_BMI.ipynb) · [`회귀분석`](src/Regression/Regression_Breakfast_BMI.ipynb) 노트북 |

## 1. 프로젝트 배경

청소년 비만은 성인기 건강 문제로 이어지는 중요한 지표입니다.
이 프로젝트는 교육부 학생건강정보센터가 공개한 **2023 학생건강검사 원자료**로 **수면·아침식사·운동 같은 생활습관이 BMI에 어떤 영향을 미치는지** 통계적으로 검증했습니다.
팀원 3명이 변수(수면 / 아침식사 / 운동)를 하나씩 맡아 같은 분석 절차로 진행했습니다.

## 2. 목표

- 탐색적 분석(EDA)으로 변수의 분포와 그룹별 특성 파악
- 데이터 특성(정규성, 등분산성)에 맞는 **적절한 검정 방법을 선택**해 그룹 간 차이 검증
- 회귀분석으로 영향의 **방향과 크기, 설명력** 해석
- 성별 × 학교급(초·중·고) **6개 그룹**으로 나누어 교란 효과 통제

## 3. 담당 분석: 아침식사 빈도 ↔ BMI

### 분석 흐름
```
 전처리     원자료 xlsx → csv 변환 · BMI 컬럼 생성 · IQR 이상치 제거 · 결측치 처리
   ▼
 EDA        빈도별 BMI 분포 · 성별/학교급 분포 · 상관계수 · 시각화
   │        └ 카이제곱 검정 → 아침식사 빈도는 성별·학교급과 유의한 연관 → 6개 그룹으로 분리 분석
   ▼
 가설검정   정규성 검정(Shapiro-Wilk · KS · QQ-plot) → 6개 그룹 모두 정규성 기각
   │        └ 등분산 검정(Levene) → 비모수 Kruskal-Wallis 검정 → Dunn 사후검정(Bonferroni 보정)
   ▼
 회귀분석   그룹별 OLS 회귀 → 회귀계수 · p-value · R² 해석
```

### 핵심 결과
| 분석 | 결과 |
|---|---|
| **연관성 (카이제곱)** | 아침식사 빈도는 성별·학교급과 통계적으로 유의한 연관이 있음 → 그룹 분리가 필요 |
| **그룹 간 차이 (Kruskal-Wallis + Dunn)** | **6개 그룹 모두** 아침식사 빈도에 따라 BMI가 유의미하게 다름(p < 0.001). 사후검정으로 *어느 빈도 구간끼리* 다른지 확인 |
| **회귀분석 (OLS)** | 회귀계수 **−0.08 ~ −0.39**, 6개 그룹 모두 p < 0.01 → **아침식사를 자주 할수록 BMI가 낮아지는 경향** |
| **설명력** | R² **0.1 ~ 1.2%** → 효과는 유의하지만 **BMI를 설명하는 비중은 매우 작음** |

### 결론
아침식사 빈도와 BMI 사이에는 **통계적으로 유의한 음의 관계**가 있습니다. 다만 설명력이 매우 낮아서, BMI는 아침식사 하나보다 **여러 생활습관과 유전·환경 요인이 함께 작용한 결과**로 보는 것이 타당합니다.
*"유의하다"와 "영향이 크다"를 구분해서 해석*한 것이 이 분석의 핵심입니다.

## 4. 문제 해결 과정

회의록에 남긴 실제 의사결정 과정입니다.

| 문제 | 판단 및 해결 |
|---|---|
| 연구 목표가 모호함 ("BMI와 수면·식습관·시력의 관계") | 건강 지표를 검토해보니 BMI 외 지표는 데이터가 부족하거나 편차가 작았음 → **"생활습관 → BMI"로 주제 재설정** |
| 식습관 관련 컬럼이 많고, 대부분 분포가 1~3에 치우침 | 분포가 고른 **아침식사 빈도로 범위를 좁혀** 분석의 명확성 확보 |
| 이상치 판별이 애매한 원자료 | 기관이 정제한 2022년 데이터를 검토한 뒤, 최신성을 위해 **2023년 데이터에 IQR 이상치 제거를 직접 적용**하기로 결정 |
| 설문 기반 순서형 범주 변수 | 연속형 처리(선형관계 해석)와 범주형 처리(그룹 간 차이)를 **둘 다 수행**해 상호 보완 |
| BMI 정규성 불충족 | 모수 검정(ANOVA) 대신 <b>비모수 검정(Kruskal-Wallis)</b>을 선택 |
